# Data Bricks Workspace 

This module will define standard data bricks workspace. A couple of notes:

> Two subnets are required

Databricks requires that a network security group is associated with public and private subnets when virtual_network_id is set. Also, both public and private subnets must be delegated to Microsoft.Databricks/workspaces.  Additional requirements are as follows:
* Both public and private subnets must have network security groups assigned. Not they can be empty NSGs; there are no specific rule requirements
* Both subnets must delegate to ```Microsoft.Databricks/workspaces```.
* Both subnets must egress directly to the internet for a specific list of IP addresses. See section "User-Defined Route Requirements".
* Data Bricks creates a storage account that requires a private endpoint, which should be managed separately. See section "Private Endpoint Requirements".

## Example Usage
```
module "data_bricks_workspace" {
    source                          = "git::https://dev.azure.com/example-org/PCET-SRE/_git/terraform_modules//azurerm/data_bricks_workspace?ref=1.0.1"

    virtual_network_id              = azurerm_virtual_network.data_bricks.id
    public_subnet_name              = azurerm_subnet.public_subnet.name
    private_subnet_name             = azurerm_subnet.private_subnet.name

    data_brick_workspace_name       = var.data_brick_workspace_name
    log_analytics_workspace_id      = var.log_analytics_workspace_id
    resource_group_name             = azurerm_resource_group.test_rg.name
    location                        = var.location
    tags                            = var.tags

}
```

## User-Defined Route Requirements

Both the public and private subnets must egree directly to the internet for specific IP addresses. This is accomplished by a User-Defined Route on the public and private subnets. IP addresses involved differ per region. This information comes from [Microsoft documentation](https://docs.microsoft.com/en-us/azure/databricks/administration-guide/cloud-configurations/azure/udr).

## Private Endpoint Requirements

A storage account is created by Data Bricks. That storage account requires a private endpoint.  Instructions for obtaining the storage account endpoint are [here](https://docs.microsoft.com/en-us/azure/databricks/administration-guide/cloud-configurations/azure/udr#dbfs-root-blob-storage-ip-address).
